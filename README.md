# CypherKit v2

Modular browser-first cybersecurity utility workbench.

## Run on Arch Linux

```bash
cd ~/cypeherkit
python -m http.server 8080 --directory frontend
```

Open: http://127.0.0.1:8080

If you downloaded this ZIP into `~/Downloads`, extract it first and then copy/rename the project as needed.

Included tools:
- Base64 / Hex / URL codec
- Hash identifier
- Password strength estimator
- JWT decoder
- URL parser
- JSON formatter/minifier
- UUID v4 generator
- Cryptographic password generator
- Local notes

Use only on systems/data you are authorized to test.
